Airline Performance Dashboard & Delay Prediction System

Author

Sabuhi Abbasov

Project Overview

This is a comprehensive airline performance dashboard and delay prediction system that combines real-time flight data monitoring with machine learning forecasting. The system provides airlines with actionable insights into their performance metrics and helps predict departure delays based on multiple factors including weather conditions, time of day, and historical patterns.

Key Features

  • Real-time Performance Monitoring: Track airline reliability metrics and on-time performance percentages
  • Weather Impact Analysis: Analyze how wind speed and other weather factors affect flight delays
  • Predictive Modeling: ML models that forecast potential delays with high accuracy
  • Interactive Dashboard: Shiny application for dynamic exploration of flight data
  • Comparative Analytics: Benchmark airline performance against global averages

Machine Learning Model Summary

The predictive model for delay estimation was trained using the tidymodels framework with the following approach:

Model Specifications

Features Used: - Airline carrier (categorical) - Departure airport (categorical) - Arrival airport (categorical) - Hour of day (temporal) - Day of week (temporal) - Wind speed (continuous)

Model Types Tested: 1. Linear Regression (baseline) 2. Random Forest with hyperparameter tuning

Data Split: - Training set: 80% of data - Test set: 20% of data - Cross-validation: 5-fold

Model Performance Comparison

The Random Forest model demonstrates superior predictive performance with lower RMSE and MAE, capturing non-linear relationships between features and departure delays more effectively than linear regression.

Feature Importance

The most influential features in predicting departure delays are:

  1. Airline Name - Different carriers have inherent reliability patterns
  2. Hour of Day - Peak hours experience different delay characteristics
  3. Departure Airport - Airport infrastructure and traffic patterns affect delays
  4. Wind Speed - Weather conditions directly impact flight operations
  5. Day of Week - Weekly patterns influence departure delays

Model Application

The trained model can be deployed to: - Provide real-time delay forecasts for scheduled flights - Identify high-risk flight combinations (airline + time + airport) - Optimize resource allocation for airline operations - Support decision-making for schedule adjustments

Interactive Dashboard

The project includes a comprehensive R Shiny application accessible via:

shiny::runApp("shiny_app.R")

The dashboard provides: - Real-time airline performance metrics - Interactive filtering by airline and time range - Dynamic visualizations of delay patterns - Weather impact analysis - Model prediction display

Technical Implementation

Python Data Pipeline

The data collection and transformation pipeline uses: - Aviation Stack API: Real-time flight data with pagination and rate limiting - Open-Meteo API: Weather data integration for historical and forecast conditions - Pandas: Data transformation and flattening of nested JSON structures - Local Caching: Development mode with fallback to live API calls

R Analytics Stack

  • Tidymodels: ML model training and evaluation
  • Tidyverse: Data manipulation and visualization
  • Shiny: Interactive dashboard framework
  • Plotly: Interactive visualizations
  • DT: Interactive data tables

Key Insights

  • Average Departure Delay: 11.3 minutes
  • On-Time Performance: 73.9%
  • Most Delayed Airline: China Southern Cargo (160.8 min avg delay)
  • Most Reliable Airline: ACE Air Cargo (100% on-time)

Conclusion

This airline performance dashboard provides a complete solution for monitoring and predicting flight delays.
